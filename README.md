# FreshNite Landing Page

FreshNite is a fictional healthy meal delivery landing page built with HTML and CSS.

## Features

- Responsive layout
- Hero section
- Meal cards
- Call-to-action buttons
- Contact form UI

## Technologies Used

- HTML
- CSS

## Live Demo

https://opeolamide.github.io/Freshnite/

I practiced page structure, responsive layout, CSS styling, cards, buttons, and section-based navigation.
